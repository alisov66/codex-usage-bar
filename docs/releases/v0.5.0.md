## What's new

- New app name and panel title: **Watch the Limits**.
- Renamed app bundle, executable, and download archive.
- Updated GitHub links, documentation, and build automation for [alisov66/watch-the-limits](https://github.com/alisov66/watch-the-limits).
- Existing menu bar preferences and saved Codex location keep the same settings domain. The macOS app identifier is intentionally unchanged.

## Install or update

1. Quit any running copy of **Codex Usage Bar** or **Watch the Limits**.
2. Download **Watch-the-Limits-macOS.zip** from Assets below and unzip it.
3. Move **Watch the Limits.app** to Applications, replacing an existing copy with that name if necessary.
4. If you previously installed **Codex Usage Bar.app**, remove that old copy after verifying the renamed app works. Keep one installed copy.
5. If you use Launch at login, check it in the renamed app and re-enable it if macOS still references the previous app path.

Requires **macOS 13 or newer**, with native Liquid Glass on macOS 26 and later. The download supports **Apple Silicon and Intel**. Codex must be installed locally and signed in with your ChatGPT account to show subscription quota.

This release is ad-hoc signed and is not notarized by Apple. If macOS blocks it, review the release and use **System Settings → Privacy & Security → Open Anyway**, when available.
