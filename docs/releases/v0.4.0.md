A redesigned usage panel with native macOS appearance and clearer loading, refresh, and setup states.

## What's new

- A new dropdown panel based on the approved Figma design, with remaining quota, progress bars, reset countdowns, and account plan.
- Native Liquid Glass in a rounded, arrow-free panel on macOS 26 and later, plus the current system switch appearance. Earlier macOS versions retain a native popover.
- Expandable Settings for menu bar display, launch at login, and Codex location.
- Dedicated loading, retry, Codex-not-found, and sign-in states. Previously loaded usage stays visible when a refresh fails; expired quota waits for fresh data.

## Fixes

- Prevent the opening click from immediately dismissing the panel, and handle screen information that is not ready on the first click.
- Keep the panel anchored while Settings expands or collapses, with Escape and outside-click dismissal.
- Load icons and design resources from the installed app, without relying on the source folder.

## Install or update

1. Quit any running copy of Codex Usage Bar.
2. Download **Codex-Usage-Bar-macOS.zip** from Assets below and unzip it.
3. Move **Codex Usage Bar.app** to Applications, replacing the previous copy, then open it.

Requires **macOS 13 or newer**. The download supports **Apple Silicon and Intel**. Codex must be installed locally and signed in with your ChatGPT account to show subscription quota.

This release is ad-hoc signed and is not notarized by Apple. If macOS blocks it, review the release and use **System Settings → Privacy & Security → Open Anyway**, when available.
