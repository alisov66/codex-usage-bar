# Approved app icon

Figma source: https://www.figma.com/design/zCrkvUn8WyWUKH3YYn6QB0?node-id=15-1883

`app-icon.svg` is the original full-color vector export of the approved 1024 × 1024 frame. `app-icon-master.png` is the original rendered export of that frame, retained as a design reference rather than a screenshot.

`CodexAppIcon.icon` is the Apple Icon Composer document containing the original SVG at its original size and position. The artwork's glass effects, specular highlights, translucency, and group shadow are disabled to preserve the approved flat design. The original opaque Figma background covers the document's underlying fill.

`Compiled/Assets.car` contains the modern macOS icon resources. `Compiled/CodexAppIcon.icns` is the conventional fallback generated by Apple's asset compiler with a macOS 13 deployment target. Both are bundled by the normal build script and registered through `CFBundleIconName` and `CFBundleIconFile`.

The compiled files are checked in so normal builds do not require a particular Icon Composer installation. Source checksums make a normal build fail if the artwork changes without regenerating its compiled resources. To regenerate them with a compatible Xcode installation:

```sh
bash scripts/build-app-icon.sh
```

Changing this icon or the app interface requires the owner's design approval. Publishing a release requires a separate confirmation, as described in `AGENTS.md`.
